# A propos de L Antre d Halloween : Le Grimoire de Minuit

**L Antre d Halloween** est un launcher gothique immersif developpe par **Geoffroy Streit** (alias **Hylst**).

## Le projet
Ce launcher fonctionne comme un sous-menu secret et immersif pour la plateforme Hylst.Games. Il regroupe les 8 mini-jeux d arcade, de survie et d énigmes crees pour Halloween, avec une ambiance gothique soignee : brume volumetrique animee en Canvas 2D, nappe musicale d orgue et de violoncelles synthetisee en direct avec l API Web Audio, et bruitages spectraux au survol et au clic.

## Le createur
- Developpeur d applications, ancien graphiste et compositeur
- Adepte de retrocomputing et de demoscene
- Createur de la plateforme de jeux 100% front-end Hylst.Games

## Stack technique
- React 19 + TypeScript + Tailwind CSS 4
- Vite 7 + vite-plugin-singlefile
- Web Audio API (zero fichier audio externe charge)
- Canvas 2D adaptatif
- 100% statique, sans serveur ni collecte de donnees
