# L Antre d Halloween : Le Grimoire de Minuit

**Launcher gothique immersif pour les jeux d Halloween de Hylst.Games.**

Joue en ligne sur : [https://games.hylst.fr/halloween/](https://games.hylst.fr/halloween/)

## Description
Ce hub thematique autonome met en valeur les 8 jeux d Halloween de la plateforme :
1. **Chasse aux Bonbons** : arcade de plateforme verticale retro (`/chassebonbons/`)
2. **Sac de Bonbons** : 16-bit vertical jumper retro (`/sacdebonbons/`)
3. **Cimetiere Clair** : horde roguelite en arene fermee (`/cimetiereclair/`)
4. **Cimetiere Ardent** : survie et defense de sanctuaire (`/cimetiereardent/`)
5. **Manoir Valombre** : escape game en point and click (`/manoirvalombre/`)
6. **Lanterne de Courge** : enquete spectrale et serrures en laiton (`/lanternecourge/`)
7. **Bonbons Monstres** : tycoon pixel art de confiserie (`/bonbonsmonstres/`)
8. **Confiserie de Minuit** : simulation de boutique ensorcelee (`/confiserieminuit/`)

## Fonctionnalites
- Arriere-plan Canvas 2D anime avec brume nocturne et braises
- Moteur audio Web Audio API procedural (musique d orgue en boucle + bruitages)
- Filtres thematiques par categorie
- Cartes illustrees haute definition avec lueurs spectrales
- Teaser pour les futurs recits interactifs (L Hotel Limbic & La Vieille Demeure)
- 100% responsive et fluide sur mobile comme sur bureau
